## Current Seed Policy

All documentation, comments, examples, and reports must match the current seed
policy split:

- run_experiment + the root run_all_cec*.m launchers default to seed_policy
  "unified" with requested generator "threefry" for fair cross-family experiments.
- gsk_run (the C++ CLI) and the shipped YAML configs default to seed_policy
  "reference" with "threefry".
- Direct lower-level run_experiment(...) calls default to "unified" unless a caller
  passes seed_policy explicitly.

The centralized default base seed is base_seed = 20240620.

Unified mode is implemented by get_cec_seed(base_seed, dim, func, run) using
uint64 arithmetic. The seed depends only on base seed, dimension, function, and
run. Unified mode also shares the runner-generated X0, restores the
post-initialization RNG state inside each optimizer, and verifies completed
run_all* schedules with verify_unified_seed_schedule(...). Unified mode uses
threefry when the installed MATLAB supports it and falls back to twister otherwise.

Unified seed formula (must read identically wherever it appears):

seed = mod(base_seed + 1000003*dim + 1000033*func + 1000037*run, 2147483646) + 1

The unified seed must NOT include optimizer name, optimizer index, alg_code,
population size, budget, suite name, or any other optimizer-specific value. Any
page implying otherwise is wrong.

Reference-mode per-optimizer seeds:

- For GSK, ATMALS-GSK, and eGSK:   seed = base_seed + 9973*func + run - 1
- For AGSK, APGSK, and FDB-AGSK:   seed = D*func*run

Under reference mode, AGSK, APGSK, FDB-AGSK, eGSK, and ATMALS-GSK use the
deterministic legacy integer seed; GSK uses twister. Under unified mode every
optimizer uses the same resolved generator (threefry if supported, else twister).
Under native/derived, the requested rand_generator (threefry, twister, seed, or
state) is honored.

## Current Output And Rerun Policy

All documentation, comments, examples, and generated HTML must match this output
contract:

- Root `run_all_cec*.m` launchers write to
  `results/_run_all/<optimizer>/<suite>/`.
- `gsk_run` writes to `results/<optimizer>/<suite>/` unless `--output` or
  `output_root` overrides it.
- `overwrite=false` resumes/appends and archives refreshed fixed-name artifacts
  under `_archive/<timestamp>/`.
- `overwrite=true` moves the previous active result tree to
  `_overwrite_archive/<suite>_<timestamp>/` under the same parent, then starts a
  clean replacement run.
- `write_graphs=false` is the default. It skips slow PNG rendering only.
  Numeric `curves/*.csv` and `gen_logs/*.csv` are still written.
- `write_graphs=true` renders display-only PNG graphs under `curves/graphs/`.

Do not rewrite the seed policy to make it simpler. The split policy is intentional
and must stay visible in user-facing documentation.

## HTML Documentation Review

The HTML site is generated by Pandoc (primary) with a built-in minimal
Markdown-to-HTML fallback renderer when Pandoc is absent, plus Doxygen for the
C++ API. The build command is:

    powershell -File scripts\build_docs.ps1 -Clean

How the build works (so you fix the right source, never the output):

- Each Markdown page maps to a flat, folder-prefixed output name under docs/html/,
  for example docs/getting-started/tutorial.md -> getting-started_tutorial.html and
  docs/reference/seed_policy.md -> reference_seed_policy.html. The page list lives
  in scripts/build_docs.ps1.
- The script post-processes generated HTML with a cross-link rewriter that turns
  relative .md links into the right .html names. It uses a basename-fallback map:
  because pages moved into subfolders, when a resolved-path lookup misses it falls
  back to matching on the unique file basename. Every source basename is unique,
  so this is unambiguous. If a link still breaks in the site, fix the source link
  or the page list, not the generated HTML.
- The sidebar nav is grouped: Getting Started, Reference, Algorithm Guides,
  Development, Prompts, Research, and a C++ API group that links to api/index.html
  (Doxygen). Each page also gets a per-page table of contents (#TOC), a light/dark
  theme toggle, per-code-block copy buttons, and mermaid rendering.
- docs/index.html is only a redirect into docs/html/index.html.

Review the generated site under docs/html after rebuilding, checking:
