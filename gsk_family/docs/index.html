gsk_family Documentation

Opening the documentation site… If you are not redirected automatically, open html/index.html. The site sidebar links every page in the docs/ folder (Getting Started, Reference, Algorithm Guides, Development, Prompts, Research, and the C++ API).

If the site has not been generated yet, build it (no Python required) with:

powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build_docs.ps1 -Clean

run from the gsk_family folder. The Markdown sources under docs/ are the source of truth; docs/html/ is regenerated.
